# 自动记账与生活管理

一款以付款截图识别和自动记账为核心的手机生活管理应用。它帮助你整理收支、安排学习与日程，并通过智能对话查找已有记录。

## 主要功能

- **截图记账**：识别付款截图中的金额、商家和付款状态，按应用设置记录账目。
- **收支管理**：查看消费明细、日期和统计信息。
- **学习与日程**：安排学习任务和生活事务，查看每日计划。
- **智能对话**：在授权范围内查询记录，结合对话历史辅助处理任务。
- **桌面小组件**：在手机桌面查看常用信息。

截图记账需要由使用者触发并授权；它不代表应用已绑定微信或支付宝，也不代表每次付款后手机都会自动截屏。识别与保存结果以应用实际提示为准。

## 仓库内容

- `app/`：手机应用、小组件、核心逻辑和测试。
- `skills/lifeos-auto-bookkeeping/`：自动记账技能，为开发者提供截图识别和账目处理的实现指南。
- `skills/lifeos-memory-action/`：智能记忆与任务操作技能。

这些技能是提供给开发工具的操作指南，不会单独连接数据库或自动获得应用权限；实际功能需要应用提供相应接口。

## 运行应用

使用 Xcode 打开 `app/LifeOS.xcodeproj`，选择 `LifeOS` 运行方案。若要安装到自己的手机，请配置自己的开发团队、应用标识和主应用与小组件共用的应用组标识。智能对话的服务地址和密钥由使用者自行配置，仓库不包含密钥。

在安装了 Xcode 的电脑上，可以运行核心测试：

```sh
cd app/LifeOSCore
swift test
```

## 安装技能

将需要的技能文件夹复制到 `~/.codex/skills/`，然后重启 Codex；也可以通过 Codex 的技能安装工具从本仓库安装。

例如，安装自动记账技能后，可以向开发工具提出：

> 使用 `$lifeos-auto-bookkeeping`，为应用增加付款截图识别和自动记账，并处理识别不确定和重复提交的情况。

## 数据与素材

公开版本排除了原设备中的对话、计划、账单、凭据和个人签名配置；测试使用匿名化样例。连接智能服务或处理真实记录时，应遵循使用者的授权。

动物头像和应用图标由图像生成工具为本版本制作，并非原动漫角色素材。使用者应根据适用地区的法律和服务条款，确认素材的再发布或商业使用条件。
